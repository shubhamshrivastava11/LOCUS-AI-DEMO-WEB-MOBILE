Security & governance

Shared memory, with real boundaries.

Every answer, digest and agent call checks role, scope and classification first. Raw content is purged after 30 days; only structured decisions persist.

Request a security reviewData processing

Controls

What Locus AI does, and what it never does.

Read-only access

Every integration uses read-only OAuth scopes. Locus AI never posts, edits or replies.

30-day raw content purge

Messages are encrypted at rest and deleted after 30 days. Only structured decisions persist.

Five roles

Owner, Admin, Lead, Member and Guest. Guests see only what is shared with them and can expire.

Four classification levels

Public, Internal, Restricted and Confidential, checked on every search, digest and agent call.

Personal sources stay personal

Records from a person’s own Gmail are visible only to them, including from Admins.

Audit log

Admin actions, role changes and every confidential access grant are recorded and exportable.

Roles

Five roles, scoped to how your org works.

RoleCan
OwnerBilling, tenant settings and ownership.
AdminConfigure sources, roles and policies without reading everything.
LeadManage the scopes their team owns.
MemberFind and use everyday team knowledge.
GuestOnly spaces explicitly shared with them; access can expire.

Classification

Four levels, checked on every request.

LevelWho can see it
PublicEveryone in the workspace and approved Guests.
InternalAll Members. The default for new records.
RestrictedMembers of the owning scope only. Never shown to Guests.
ConfidentialExplicit grants only. Every access is logged.

Data handling

Minimal by design.

  • Read-only OAuth scopes, chosen per channel, label, space or project.
  • Raw messages encrypted at rest and purged after 30 days.
  • Structured decisions kept until an Admin deletes them.
  • Personal sources visible only to their owner, including from Admins.
  • Agents get the same permissions as the person they act for.
